# Carousel Lamp · 旋转木马相片灯

把喜欢的相片挂在旋转木马上，点亮夜晚，让它慢慢转起来。

这是一个可以在浏览器中操作的 3D 相片灯。首次打开有 **16 个空相框**，不附带个人照片，无需登录或 AI API Key。

## 可以做什么

- 切换日夜模式，欣赏灯光和星光。
- 点击「挂相片」，选择单张挂片或批量上传。
- 批量最多选择剩余空位数量的相片（最多 16 张），随机填入空相框，已有相片与位置保持不变。默认居中裁剪，挂好后可单独调整。
- 批量准备完成后统一保存；超量、无效文件或保存失败不会只挂上一部分。
- 调整相片大小、水平和垂直位置。
- 点击相框查看、重新调整、更换或取下相片。
- 长按相片约半秒，拖到另一张相片上，松手交换位置。
- 点击「起风」让挂饰摆动，点击「旋转」让木马顺时针转动。
- 自动保存相片、裁剪、位置，以及视角和日夜模式。

## 在自己电脑上运行

先安装 Node.js 22.13 或更高版本（推荐 Node.js 22 LTS），以及随附的 npm。

下载本仓库的 ZIP 并解压，在项目文件夹中打开终端，依次执行：

```sh
npm ci
npm run dev
```

打开终端打印的本地地址。停止运行时，在终端按 `Ctrl+C`。

项目基于 React、Three.js、Vinext 和 Cloudflare Workers。运行网页不需要 Codex 或 OpenAI 账号。

## 相片和隐私

- 支持 JPG、PNG、WebP、HEIC/HEIF，单张最大 50 MB。HEIC/HEIF 在浏览器后台转换为 JPEG，最长边限制为 2560 像素后用于裁剪和保存；原文件不修改。
- 选择的文件在浏览器内读取和裁剪，相片不上传到服务器。
- 相片使用 IndexedDB 保存；视角和模式使用 localStorage 保存。
- 保存内容属于当前设备、浏览器和网站地址。换浏览器、换端口或换域名不会自动同步。
- 清除网站数据、使用无痕模式或浏览器回收存储空间，可能导致相片丢失；请保留原图。
- 把网页链接发给朋友，不会同时分享你挂好的照片。每个人看到的是自己浏览器保存的内容。

## 检查和构建

```sh
npm run typecheck
npm run build
npm start
```

`npm start` 在本机预览构建后的 Cloudflare Worker，以终端打印的地址为准。

## 在线部署

上传 GitHub 只会公开源代码，不会自动生成可访问的网页。

此版本的构建输出是 Cloudflare Worker，**不能把整个仓库直接交给 GitHub Pages**。可以在构建成功后，使用自己的 Cloudflare 账号，通过 Wrangler 部署 `dist/server/wrangler.json`；部署前应检查目标 Worker 名称，避免覆盖已有项目。

`.openai/hosting.json` 只保留空的资源绑定配置，没有原作者的项目 ID。通过 Sites 发布时，需要为自己的副本注册项目。

## 目录

- `app/`：页面、相片编辑器和样式。
- `lib/carousel-scene.ts`：木马、相框、灯光和操作。
- `lib/photos.ts`：相片读取与裁剪。
- `lib/photo-storage.ts`：本地相片保存。
- `lib/view-storage.ts`：视角和模式保存。
- `public/`：界面装饰图、花纹贴图和字体，不包含用户相片。
